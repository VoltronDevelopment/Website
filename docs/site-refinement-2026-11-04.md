This local implementation follows the complete-site audit. It preserves routing, shared navigation, approved geometry, typography and the existing sequence of sections.

## Scene changes

Commons creative exchange brings two perspectives toward a component; systems thinking traces orthogonal relationships; inquiry separates and scans the component; nature resolves planting around the study. Participation now shows experience transfer, a shared component study, or a planted initiative, rather than repeating one cube-merging sequence.

Partner's process now gathers a brief, closes a review gate, and delivers the next-step record with three resolved indicators. These are illustrative collaboration stages, not an automatic approval claim. All introductions remain finite, selection remains explicit, and rendering suspends offscreen.

Shared material configuration now updates only when the theme changes. Inactive groups are no longer traversed every rendered frame. Contribution endpoints are allocated once rather than inside each update.

## Native artwork delivery

Both study review scripts now export `canvas.toDataURL` rather than a composited page screenshot. PNG masters preserve transparency and exclude page gradients/HTML controls. All 76 Commons/Partner study images and eight Partner hero images were regenerated in both themes and desktop/mobile projections.

`node scripts/encode-study-posters.mjs` creates native-resolution WebP delivery copies, with lossless alpha and quality 92 color. The 84 copies total 13,389,896 bytes against 29,319,439 bytes for PNG masters (54% smaller). Only the selected study is displayed; raw masters remain available for future exports.

After changing scenes, run the relevant review script, then the encoder, then the production build so packaged public assets match the renderer.
