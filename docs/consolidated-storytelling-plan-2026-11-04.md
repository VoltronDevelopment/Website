## Six cloud identities

Keep the same density field and advected material through state changes. Do not fade it out and replace it with independent geometric targets.

- KAVO: broad folds compress into ordered cloud layers, then relax.
- RIXA: fine cloud briefly clears around a traveling inspection front; denser evidence areas resolve.
- MEKO: deep, slow rolling density with a soft internal circulation; no literal ring stacks.
- ZILO: faster directional ribbons that remain broad volumetric streams; not isolated wire strands.
- SARO: fine motes remain embedded in a pale cloud, gather into soft concentrations, then rejoin.
- TEYO: several irregular cloud lobes converge and resolve into a single connected field; no node-and-edge diagram.

State changes modulate the existing field's velocity, density, anisotropy and local clarity. Use smooth bounded transitions with no apparent material disappearance. Keep state labels textual, beside the cube; decorative activity must not masquerade as live agent work. Stagger peaks and keep outer shells stable.
