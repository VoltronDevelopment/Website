# Network assets

Route: `/network`



- `N01-network-hero-light.webp` and `N01-network-hero-dark.webp`: Connected plants sharing one architecture. Recommended source: 1200 x 1000px.
- `N04-compounding-network-light.webp` and `N04-compounding-network-dark.webp`: Learning across a governed network. Recommended source: 1200 x 900px.
- `N05-industrial-products-light.webp` and `N05-industrial-products-dark.webp`: Industrial products as a future direction. Recommended source: 1200 x 900px.

Transparent WebP is preferred. A matching `-light.svg` or `-dark.svg` takes precedence when supplied. For PNG, change the corresponding manifest `image` filename to `.png`. Upload only one format per theme. Keep the same composition, crop and aspect ratio in both themes. Do not include UI text, labels, buttons or a baked page background. Existing source assets must remain intact. Missing files reserve the artwork space without broken-image icons.
