# Manufacturing Ontology assets

Route: `/ontology`



- `O01-ontology-hero-light.webp` and `O01-ontology-hero-dark.webp`: Manufacturing identity and meaning hero. Recommended source: 1200 x 1000px.
- `O03-identity-relationships-light.webp` and `O03-identity-relationships-dark.webp`: Plant, part, lot, operation and machine relationships. Recommended source: 1000 x 900px.
- `O04-manufacturing-relationships-light.webp` and `O04-manufacturing-relationships-dark.webp`: Requirements, processes, equipment, inspection and evidence. Recommended source: 1000 x 900px.

Transparent WebP is preferred. A matching `-light.svg` or `-dark.svg` takes precedence when supplied. For PNG, change the corresponding manifest `image` filename to `.png`. Upload only one format per theme. Keep the same composition, crop and aspect ratio in both themes. Do not include UI text, labels, buttons or a baked page background. Existing source assets must remain intact. Missing files reserve the artwork space without broken-image icons.
