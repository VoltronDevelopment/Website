# Brand voice and design context

## Enduring direction
Organic growth through engineered structure. The leaf–circuit V, lattice geometry, restrained light and careful spatial relationships express this idea. Preserve the supplied logo rather than redrawing it from screenshots.

## Voice
Use precise, calm, compact sentences. Explain a concrete relationship before introducing a new technical term. Balance technical credibility with human purpose. Avoid inflated performance claims, jargon-heavy introductions and broad claims of national decline. Keep the invitation practical: start with what the visitor is building.

## Visual context for the agent
The user requested a minimal cube control and a functional chat window consistent with the website’s glass surfaces, blue/navy palette and restrained illumination. Differentiate the page’s atmospheric background from cards and the chat surface. Motion should carry meaning and not obstruct reading, navigation or forms.

## Historical specification caveat
The October light-theme specification includes exact colors and Inter typography, while subsequent discussion explores frosted glass, dark themes and other typography preferences. This package does not declare those older tokens the final implemented brand system. Match the current approved site design when building the agent.

## Names
The owner subsequently selected Vera. Use the current website typography and the Voltron agent cube family. Lila informs interaction principles only.
