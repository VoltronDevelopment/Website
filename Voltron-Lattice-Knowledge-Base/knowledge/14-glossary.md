# Public terminology and aliases

| Term | Public meaning | Qualification |
|---|---|---|
| Voltron Lattice | Public company/brand identity | Legal identity is not established here. |
| VOS | Voltron manufacturing operating-system direction | Execution + Context + Intelligence. |
| V-MO / VMO | Manufacturing ontology direction | Shared manufacturing meaning, not a disclosed schema. |
| Alpha | First manufacturing application environment | Readiness must be confirmed. |
| Voltron Core | Reusable industrial foundation in the blueprint | Conceptual public label; availability not confirmed. |
| Process Pack | Reusable knowledge/configuration for a process family | Each family still requires validation. |
| Human Lattice | Individual development within a coherent whole | Organizational philosophy. |
| People Culture | Intended working and development conditions inside Voltron | Not a benefits or hiring promise. |
| Commons | Wider access, learning and possibility | Developing vision. |
| ERP | Business and production records/workflows | Generic role, not proof of a live integration. |
| QMS | Quality management and associated evidence/workflows | Generic role. |
| SCADA | Industrial supervision and monitoring | Generic role. |
| PLC | Programmable logic controller for machine/control tasks | Not the conversational agent. |
| Historian | Time-oriented industrial records | Generic role. |
| Twin | A digital representation of relevant industrial state | Not necessarily a photorealistic model. |
| CED | Cathodic electrodeposition in the surface-treatment context | Availability and suitability need confirmation. |
| Coherence | Distinct systems working with meaningful relationships and responsibilities | Does not erase independence. |

Use expansions only when they help the visitor. Do not overwhelm a newcomer with acronyms. “Execution/context/intelligence” are conceptual roles, not three independently purchasable products established by this package.
